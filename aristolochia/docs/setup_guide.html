Aristolochia Survey Field Setup

Recording garden and forest plots, and the Aristolochia vines on them — the plant the large birdwing butterflies lay their eggs on.

ForAvril Matawan

What this app does

It runs on your phone with no internet. You set it up once, and after that it works anywhere — out in the garden or forest, in the village, with the phone in airplane mode.

Internet is needed for two things only: installing it the first time, and sending each day's data to Google Drive.

Two apps — don't mix them up

Both may be on the phone. They keep completely separate records, and updating one never touches the other.

Before you start

  • An Android phone with the Chrome browser — the default on most phones.
  • The phone's date and time set to automatic (Settings → System → Date & time). The app stamps every plot with the date and works out fallow age from the year, so a wrong clock puts wrong data in the file.
  • When it asks to use Location, tap Allow.
  • The Google Drive app installed and signed in to the account that can write to the MCA_QABB_Avril folder.
Worth knowing

This app does record a GPS point of every plot. That is deliberate, and the consent script tells the farmer so before anything is written down. It is different from the hunting survey, which never records where anyone hunts.

Installing

A link

Recommended

Ask your supervisor for the link before you go to the field.

  1. While you have internet, tap the link. The app opens in Chrome.

  2. Tap the ⋮ menu (three dots, top right) → Install. Some phones say Install app or Add to Home screen — all the same thing.

    • Do not tap "Create shortcut." That only makes a bookmark, not the app.

  3. Confirm. A blue MCA Aristolochia icon appears on your home screen.

  4. Open it from that icon from now on. You do not need internet again until you send the data in.

Good sign

Seeing Install in the menu means the app is installing properly, not just being bookmarked — and that the one-tap Send will work.

A file

Only if you can't get a link

The file is called MCA_Aristolochia_Survey.html.

  1. Save it to the phone. Do not move or rename it afterwards — if the file moves, the app will not find plots you already saved.

  2. Open it. If the phone asks which app to use, choose Chrome.

  3. Check it remembers things before using it for real. Record a pretend plot, complete it, fully close Chrome, then open the file again.

    • Pretend plot still on the home screen → the file method works on this phone.
    • Pretend plot gone → stop and ask for the link instead. Some phones do not let a file opened from storage save anything.

  4. Delete the pretend plot once you are satisfied.

The first time you open it

  1. It asks for your name or ID. Type Avril Matawan and tap Save and continue. This stays on the phone and is attached to every plot you record.

  2. You land on the home screen, with an empty list of plots.

Test it offline, before your first real garden

  1. Turn on airplane mode.

  2. Record a pretend plot all the way through to Complete plot.

  3. Close the app completely, then reopen it. The pretend plot should still be there.

  4. Delete it with the Delete button on the home screen.

If all of that works, the app is ready for the field.

Recording a plot

Any question can be left blank, and your work saves as you go.

  1. On the home screen tap + New plot.

  2. Read the consent script aloud. It asks permission to walk the place — garden or forest — and to record the farmer's name, what is there, and a GPS point.

    • Farmer agrees → tick the box, tap Start recording.
    • Farmer does not agree → tap Declined — cancel. Nothing is saved.

  3. Section A — Plot and farmer. The GPS point is taken automatically when the plot opens. Fill in the farmer's name, village, Zone and Ward.

    • If it says No GPS point, move to open sky away from thick canopy and tap Retry GPS.
    • The plot code — like Z6-M46-001 — appears once you choose the Zone. You never type it yourself.

  4. Section B — Garden or forest. First say whether the plot is a garden or forest. The rest of the section changes to match.

    • Garden — garden type and description, the year cleared, whether it is still gardened or abandoned, and the year abandoned. Fallow age is worked out for you and shown in the blue box; don't try to type it.
    • Forest — forest type and description only. No year is asked, and there is no fallow age: the box says forest, age not determined.
    • If you pick the wrong one and change it, the answers from the other side are cleared. Re-enter them if you switch back.

  5. Section C — Aristolochia. Answer whether it is present. If yes, tap + Add vine for every vine you find — the same on a garden plot and a forest plot — and for each one record the tree it is climbing, that tree's DBH in centimetres, and whether there is a caterpillar, an egg, or signs of leaves being eaten.

    • A count box appears when you answer Yes. Fill it in if you can count them; leave it blank if you cannot.
    • The butterfly species question only appears once you have recorded a caterpillar, egg or feeding sign.

  6. Tap Review. Check what is recorded, read the thank-you aloud, then tap Complete plot.

On forest plots

A forest plot gets no age. That is how the app is meant to work — the age of forest is not determined by this survey, and a blank there is a correct answer, not a missing one. Only write an age into the description if somebody actually knows it.

On naming the butterfly

Only choose O. priamus or O. alexandrae if you are sure. If you are not sure, leave it as not identified — that is a normal answer, not a gap. A wrong identification is worse than none.

Sending the day's data — every evening

You need internet for this step.

  1. Open the app. The home screen shows Today, with how many plots are completed and how many are not yet exported.

  2. Tap Send today's data. That is the only button you need.

  3. The phone's share sheet opens. Choose Drive, pick the MCA_QABB_Avril folder, and save.

  4. Check the home screen now says 0 not yet exported.

Two files go together in that one tap:

mca_aristolochia_plots_<date>.csv
One row per plot
mca_aristolochia_vines_<date>.csv
One row per vine

They are separate because a plot can have any number of vines. Keep both — the office needs the pair.

The share sheet needs the link install

Android only offers the share sheet to a page served over the internet. If you installed from the file, it will not appear — the app downloads the two files instead and tells you so, and you upload them from Downloads with the Google Drive app. This is the main reason to prefer the link.

Only plots you marked Complete are exported — a plot still in progress is held back until you finish it. If you were out of signal for a few days, the home screen tells you how many older plots are still waiting; use Other export options → Send everything not yet sent to catch up.

Protecting the data

Plots live only on this phone until you export them.

These three things lose data permanently

Clearing Chrome's browsing data or site data while plots are unexported — it deletes the saved plots. Uninstalling the app, or deleting the file, before exporting. Losing or breaking the phone before exporting.

All three have the same protection: export every day you record anything. Deleting a plot with the Delete button also cannot be undone.

If something goes wrong

GPS says "No GPS point"

Check Location is switched on in the phone's settings. Move out from under thick canopy to open sky and tap Retry GPS. If it says permission is blocked, tap the padlock or ⋮ in Chrome's address bar → Permissions → Location → Allow, then Retry. You can still record the rest of the plot without a point — it is flagged at Review so the office knows.

The app opens but my plots are gone

Most often the app was opened a different way than usual — a different link, or a file that was moved. Open it exactly the way you did before. If you used the file method and the file was moved or renamed, move it back.

A plot I finished still says "in progress"

Open it, tap through to Review, and tap Complete plot. Only completed plots export.

Export did nothing, or only one file arrived

The two files download a moment apart — check Downloads for both. If a plot is still in progress it will not be in the export.
